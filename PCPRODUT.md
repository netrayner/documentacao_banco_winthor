## 🏷️ Classificação de Mercadoria (`TIPOMERC`) - Rotina 203 do WinThor

Na rotina **203 - Cadastrar Produto** do WinThor, a coluna `TIPOMERC` (`VARCHAR2(2)`) define o tipo de mercadoria do produto. No ecossistema **Insights Navigator**, apenas os produtos do tipo **Liberado (L)** são classificados como **Produtos para Revenda** (`revenda = true`). Todos os demais tipos são classificados como **Uso Interno / Consumo / Insumos** (`revenda = false`).

### Regra de Extração SQL no Integrador:
```sql
UPPER(TRIM(NVL(P.TIPOMERC, ''))) AS "tipomerc",
CASE 
  WHEN UPPER(TRIM(NVL(P.TIPOMERC, ''))) = 'L' AND NVL(P.REVENDA, 'S') <> 'N' THEN 'S'
  ELSE 'N'
END AS "revenda"
```

O integrador sincroniza tanto o campo booleano `revenda` quanto o código original `tipo_merc` (`VARCHAR`/`TEXT` no Supabase) para permitir análises detalhadas por tipo de mercadoria.
